# 辅料配对经验变化

初版：20种常见辅料、190种无序配对。catalog.json 是物料与关系索引，不是190组已经验证的模型。目前仅MCC—预胶化淀粉连接三个分开保存的来源研究。

## 增补证据的统一要求

每项研究独立保存：文献/专利族、原文地址和表页定位、数据提取方式、API和剂型、各物料品牌规格粒径、完整处方及质量基准、补差物料、工艺与加入方式、检测介质/装置/体积/转速/温度、逐点响应、重复数及误差类型、原文冲突和缺项。

先区分固定两物料合量的一维路径，与第三物料补差的双因素设计。两点只能支持来源配对差及局部割线；足够的设计数据才拟合响应面。不能把品牌、工艺或检测条件不同的研究混池成通用系数。报告系数及单位、编码、适用范围、逐点残差、留出误差和确认试验。无数据不生成模型。

新配对需增加经过核验的研究数据和专属计算/展示适配器，再更新catalog.relations。仅新增目录条目或研究报告不会自动升级为已验证关系。当前适配器仅支持mcc-pgs-conditional-v1。

## 现有页面

第二智能体已保存方案下方：配对选择、研究要求、190配对可筛选目录、来源公式计算器、来源图与当前目标适用性。选择保持在浏览器，来源与目标处方不改写。研究包可导出JSON。专项问题仅在当前冻结方案含两个已有物料且至少一项实际改变时交接给研究输入；不会自动启动或采纳参数。

来源计算器的PGS/MCC质量百分比仅属于西地那非来源条件。默认固定两物料合量，另可分别调整并由来源处方的甘露醇补差。Q15、崩解分别计算；超范围或缺输入阻断。不得将来源估计标成诺氟沙星实测/已验证预测。

## 2026-09-24验证

TypeScript检查、trial构建通过；20物料唯一性、190配对唯一性、18个来源模型点与后端复算一致，越界及空值阻断通过。真实页面验证默认试算、越界提示、待检索配对无来源曲线、缺物料研究按钮禁用及专项问题交接。未修改用户处方或启动新的研究任务。
