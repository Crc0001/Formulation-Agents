# 模型驱动的两个智能体交付约定 v1

只处理原研处方工艺及辅料筛选。本轮不申称放大、免BE或商业化成立。研究目标是先产生可检验预测，再选择有区分力的锚点；无本品实验不阻止跨药建模，不能仅以缺数据结束。

输出 ResearchReport.research_design（model-led-v1）。兼容旧字段，但不能用旧报告摘要替代模型包。原研智能体保留原研/参比身份和多个专利开发候选，绑定组成、工艺、来源溶出及质量基准，列出可筛选因素；不把专利自动当商业原研处方。筛选智能体严格绑定冻结两方，固定种类和API，包含全部补差变化，优先复用第一智能体模型包及已归档证据。

hypotheses 每个模型必须交付具体 equation、mapping（组成/规格/工艺→中间物性→性能）、parameters（值或范围、单位、依据与缺项）、domain、source_ids、calibration、holdout、falsifier。允许经验、机理、混合模型；模型不可辨识时保留竞争解释，不能为凑数量强造两个。proposed/来源已计算/目标条件计算分别标记。不得用文字方程冒充执行。已有计算工具能执行则执行；新求解器未实现写明待实现输入输出，并保留可算的局部结果。

candidates 写候选身份、实际变化、priority_anchor/retain/defer、rationale、reversal（什么结果会推翻选择）。优先锚点不是推荐投料；未知方向不硬排最佳。先查可比跨药原始设计数据，不限BCS，独立研究不混成通用系数。来源/目标与校准/留出分开，不把训练误差当迁移验证。

anchors 写固定条件、变化因素、observable、unit、purpose、qualitative_predictions（各模型如何分歧）、decision_rule、priority_reason。校准和验证不能使用同一组结果同时自证。只有实际保存计算的预测才写 predictions，每项引用hypothesis身份的计算证据ID；无数值时列表为空，保留定性判别设计。measurement_sd须有来源依据，不能填默认噪声。程序仅算同一锚点同指标同单位的模型最大最小差及有据噪声归一化分歧，不称贝叶斯信息增益，不保证全局最少试验。锚点数量由可识别性、成本与实验精度决定，不能保证三个点解决所有机制。

next_research 必须含具体补查对象/参数/原文，不能只有“建议实验”。不自动改处方、采纳参数或新增实验结果。模型包是该轮冻结输入的研究版本。

诺氟沙星MCC/PGS示例仅作任务结构，不是新增证据：可比较组成经验响应、干法颗粒进液控制和湿态解聚控制；检索各自参数映射与同条件对照。西地那非来源响应面只能复算其条件，不把系数叠加到诺氟沙星溶出曲线。锚点优先测模型预测分歧的可观测量，例如相同润滑历史下吸液和湿态颗粒演化；尚未算出差异时仅为候选判别设计。98mg原料与项目200mg身份须核对，不能静默归一化。
