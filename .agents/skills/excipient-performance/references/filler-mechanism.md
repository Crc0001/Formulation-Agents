# 填充剂替换的物理模型 v0.1

适用任务：乳糖牌号/粒度改变、乳糖与原生淀粉恒质量替换，首先分析直混胶囊。湿法制粒、糊化、包衣或API晶型改变需要另建对应结构，不能沿用直混参数。模型状态：**可执行的几何、粉床和瞬时传质模块，加上待验证的占位闭合关系；尚未校准为氟桂利嗪处方预测器。**

## 先区分五个中间量

1. 干粉流动/充填：黏聚力、摩擦、堆积状态；决定装量及混合历史，不等于水中解聚。
2. API在载体表面的占位与原有团聚：需要API—载体和API—API相互作用，不由填料名称决定。
3. 粉床进水：孔隙、渗透率、实际混合物动态接触角。
4. 载体溶解/膨胀及API释放：乳糖溶解移除支撑、淀粉吸水和膨胀可解聚，也可能改变孔道；API脱附不是必然单粒分散。
5. 可接触API表面积和传质：分散粒子与团聚体分别贡献；润湿率、团聚度、溶解度不能彼此替代。

**乳糖换淀粉导致减速的待检验路径**：可溶支撑面积减少或API捕获/分离效率降低 → 湿润后单粒比例下降/团聚尺寸增加 → 有效表面积减少。若同时进水变慢、润滑覆盖增强，减速可加剧；若淀粉促使粉塞迅速破碎，则可能抵消。合理模型必须允许这些竞争路径，不能把减速直接写进“淀粉”标签。

## A. 粒度分布 → 面积、容量和接触负荷

以下统一SI：质量kg、密度kg/m³、粒径m、面积m²、时间s。

同密度球形颗粒的质量分数粒度分布为w_j：

`1/d32 = Σ(w_j/d_j)`；`S_i = 6 m_i/(ρ_i d32_i)`。

这里d32是表面积—体积平均径；供应商d50和筛网号不能替代。非球形应使用独立形状修正或可用于外表面的实测面积；BET内孔面积未必可供API占位。不同粒级的团聚会改变实际可用面积。

API理想投影足迹 `Afoot = 3 M_API/(2ρ_API d32_API)`。令a_i为载体外表面中能实际提供单层足迹的比例，包含遮蔽和堆积损失：

`Γ_i = a_i S_i/Afoot`。

Γ是无量纲的**几何容量**，不是实际分散比例。该单层近似要求API比载体小得多，近似球形且不形成多层。API/细乳糖尺寸接近时应停止这个近似，改用粒级接触或实测空间分布。a_i不能随意指定为乳糖1、淀粉0。

竞争占位候选：`df_i/dE = k_on,i u(Γ_i−f_i) − k_off,i f_i`，`u=1−Σf_i`。

E是实际传递到粉体的比混合能(J/kg)，两个k单位为kg/J。理想稳态有 `f_i=Γ_i u/(K_i+u)`，`K_i=k_off,i/k_on,i`，由质量守恒解u。f_i为被第i种载体支撑的API质量比例；u只是未被支撑，不等同全部团聚。**这条有限位点动力学是本次提出的闭合假设，不是文献已验证的通用方程。** 脚本只实现稳态解；短混合不能冒充稳态。用显微/化学成像及不同混合能的分散测量检验，不能单凭溶出曲线同时反算全部Γ、K。

黏附力的机理候选是光滑弹性球JKR/DMT接触：`F_pull ∝ R* W_API,i`，其中W为黏附功(J/m²)。表面粗糙度、湿度液桥、静电以及塑性破坏均会改变该关系，不能把它直接当K。干粉可用 `Bo=F_cohesion/(m_particle g)` 描述黏聚相对重力，流动另需摩擦/屈服数据。Hausner/Carr是测量指标，不加权平均后直接变成溶出常数。

## B. 粉床 → 进水

`ε = 1 − Σ(m_i/ρ_i)/V_bed`。V_bed取实际充填粉塞体积；不能将各粉末松密度线性加权当作混合物密度。

刚性、均匀、连通孔隙且毛细作用主导时，由Darcy和毛细压力得：

`p_c=2γ cosθ_eff/r_p`；`l²=B t`；`B=4 k γ cosθ_eff/(μ ε r_p)`。

k单位m²，r_p单位m，γ为N/m，μ为Pa·s，B为m²/s。进水时间 `t_w=L²/B`。θ≥90°时此模型不产生自发进水，不意味着有搅拌/外压时永不润湿。

若需由粒度估k，可以提出Kozeny–Carman近似 `k≈ε³/[K0 S_v²(1−ε)²]`，S_v为每固相体积外面积(m⁻¹)。K0和等效孔径须经该粉床核验；脚本没有把180或某固定孔径比强行设为本品参数。动态θ应来自实际混合物、同介质和润滑历史；不能用纯辅料静态压片角按质量平均。

乳糖溶解、淀粉膨胀、粉塞破裂使ε、k、r_p及L随时间改变。静态式只用于早期/局部或验证后区间。不能把纯乳糖在乳糖饱和液中的测量值当整粒胶囊进水系数。

## C. 载体释放 → 单粒比例与团聚体

在明确的润湿后时点，`f = Σ(f_i η_i) + u η_u`；η_i是该载体上的API成为可接触单粒的比例，η_u是未支撑API中单粒比例。剩余质量只有在确认已成为团聚体时才进入下式；仍未释放/埋藏的API须另列不可及质量。乳糖溶解率不直接等于η_i；淀粉的η也不能默认0。

更完整时间模型应给每种载体独立溶解/吸水动力学，并追踪API粒级。质量守恒：未润湿API+湿润未释放API+分散API+团聚API+已溶API=M0。解聚/再团聚为池间转移，不创造质量。多孔团聚需孔内传质；不可把激光“团聚体直径”直接当致密球径。

## D. 分散 → 有效面积 → 瞬时溶出

最小可检验子模型：已释放API质量M_s、单粒比例f、单粒径d、致密且内部不可及的团聚体径d_g，二者相同真密度ρ。已接触液体的比例为w：

`A_eff = w·(6 M_s/ρ)·[f/d + (1−f)/d_g]`。

同一扩散层近似下：`dM_diss/dt = (D/h) A_eff [Cs−C_bulk]_+`。

该式量纲kg/s；API盐质量/活性当量必须与Cs一致。不同粒级h不同或孔内扩散重要时，应分别求和而非共用h。令R=d_g/d，则相对完全分散面积为

`g(f,R)=f+(1−f)/R`。

所以 `∂g/∂f=1−1/R≥0`，`∂g/∂R=−(1−f)/R²≤0`。这提供用户所述机制的数学条件：在传质、溶解度和润湿不改善到足以抵消时，f下降/R增加必然使瞬时速率降低。

恒剩余API量与原生粒度时，替换后/前速率比为

`J1/J0 = (w1/w0)(D1/h1)/(D0/h0) · (Cs1−C1)/(Cs0−C0) · g(f1,R1)/g(f0,R0)`。

绝不能把这条瞬时关系直接称作15/30/60分钟溶出百分比。全曲线还须积分API缩粒、载体释放、再团聚及有限介质容量；当前脚本没有执行这些动态预测。

## 氟桂利嗪例2的可计算项和识别顺序

已归档160.5mg/粒：盐酸氟桂利嗪5.9、乳糖70为29、乳糖200为87、淀粉25、二氧化硅0.6、滑石粉12、硬脂酸镁1。演示10mg乳糖按1:3替换成淀粉，只是研究情景：70→26.5、200→79.5、淀粉→35。

在两牌号各自面积与可用比例保持不变的条件下，**乳糖支持面积项降低10/116=8.62%**，API相对乳糖面积的负荷增加116/106−1=9.43%。这是组成/几何比例，不是总支持面积减少8.62%，更不是溶出减少8.62%。新增淀粉面积及捕获、释放效率仍须进入比较。选择仅替换70或仅替换200会产生不同的面积变化，不能只按乳糖总量处理。

优先用已取得的物料实测/供应商完整PSD、真密度、混合物渗透试验、API分散粒度/成像以及润滑历史逐边定参；继续查同牌号/相同方法原始资料，缺失才形成具体实验建议。不得把几十个未知参数都交给一条Q曲线优化。第一步分别核验面积/占位、进水和湿润后PSD；第二步使用独立传质参数预测瞬时速率；最后才推进跨处方曲线验证。
