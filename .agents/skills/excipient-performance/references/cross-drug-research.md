# 跨药物辅料机制专项

默认交付采用[通用双栏流程](paired-workflow.md)：左侧来源原/变化方案实测与模拟，右侧目标基线和条件预测。研究过程跨药物，模型选择按辅料实际作用；不将吡罗昔康—氟桂利嗪案例的系数推广为其它辅料系数。

## 1. 用替换问题定义检索

先写问题卡：原物料→替换物料，改变用量/比例/规格/阶段，保持总质量还是体积，允许哪些工艺变化，目标性能与当前未知。例如“恒总质量下天然玉米淀粉替换研磨乳糖，胶囊内容物分散与难溶API溶出怎样变化”。不预设变快或变慢。

用四条路径并行规划检索（不意味着必须启用子代理）：

| 路径 | 检索范围 | 要得到的证据 |
| --- | --- | --- |
| 目标体系 | 目标药物、同剂型/工艺及相关专利 | 校准或目标核验数据 |
| 跨药物对照 | 难溶性/BCS II类、其他药物的相同辅料变化 | 比例、规格、工艺的成对/多因素效果与反例 |
| 中间物性 | 可含无API粉体体系、其他BCS类别、模型颗粒 | 吸水、孔隙、润湿、解聚、表面覆盖及颗粒形成关系 |
| 理论/模型 | 对应中间量的物理关系及独立验证研究 | 可执行方程、边界条件、量纲与参数识别方法 |

英文和中文组合检索，避免始终把目标药名放入每条查询。乳糖/淀粉示例：

- `(lactose AND starch) AND (replacement OR ratio OR diluent) AND (capsule OR dissolution)`
- `(poorly soluble OR BCS II) AND (lactose OR maize starch) AND (wetting OR deagglomeration OR porosity)`
- `(native starch OR pregelatinized starch) AND (wet granulation OR dry blend) AND drug release`
- `乳糖 淀粉 替换 比例 胶囊 溶出`；`难溶性药物 辅料 润湿 分散 孔隙`
- 增加 `no effect / reduced dissolution / interaction / overmixing` 或中文对应词追查反证，不只检索“enhancement”。

按可用渠道覆盖学术元数据/摘要、期刊全文/机构仓储、专利及供应商原始物性；记录渠道实际可用性，不虚称用了不可访问的数据库。对直接相关研究查参考文献与后续引用，追补充材料、学位论文或作者公开版本。引用综述中的具体结论前回溯原始研究。专利家族、预印本/期刊版和重复数据归到同一studyFamily，不重复计权。

每次检索保存日期、渠道、确切查询、筛选范围/页数、纳入ID、排除理由、全文获取状态、新增数据与新机制。遇访问失败先尝试DOI、机构库或期刊公开版本；仍未取得标 `fulltext_unavailable`。摘要只进入机制线索，不充当完整数值数据集。

不预设读几篇就完成。维护“路径×关键因素”覆盖表；重要遗漏优先补查。若连续扩展查询及引用追查仅返回重复资料，且关键路径已检查，可报告阶段性饱和及未取得项；若因时间、权限或资源停止，直说阶段性未完成。不能声称搜尽所有文献，也不能把饱和当科学充分。

## 2. 逐研究提取，不先混池

每行以 `studyFamily / experiment / batch / arm / endpoint` 唯一标识。保留原始数据与标准化数据、转换公式，空值为null。

| 数据组 | 必要内容 |
| --- | --- |
| 来源与可读性 | DOI/URL、版本、正文/补充材料定位、原表/图、提取方式、原始单位、访问日期 |
| API | 身份、盐/晶型/水合物、剂量基准、粒度分布与测法、密度/溶解度/电离等相关实测；BCS声明及其来源单列 |
| 辅料 | 名称、牌号、供应商、粒度/形态/含水等相关属性、全部组成、绝对量与分数、加入形式和阶段 |
| 工艺与剂型 | 直混/湿法/干法、液体和固比、混合条件、干燥、整粒、压片或胶囊填充压实、壳、包装/储存 |
| 中间属性 | 润湿/吸水曲线、接触角、孔隙与渗透、颗粒/团聚粒度、解聚、可接触表面积等实际测得项目；没有就注明没有 |
| 性能与方法 | 溶出逐点、分散/崩解、强度的对象、稳定性指标；介质组成、pH、缓冲、表活、体积、转速、温度、取样补液、壳处理 |
| 设计与不确定性 | 独立批数与杯/粒重复数、均值/SD/SE区分、随机化、同时变化因素、原作者解释与本次推断分别记录 |

天然淀粉的植物来源、预胶化程度、改性品和SSG等超级崩解剂分别建身份；不能共享一个“淀粉系数”。API与辅料粒径不能互换；平均粒径、d50、筛余比例不能当同一口径。

优先原表与补充数据。只有曲线图时：确实查看图、保存图定位，标为图上数字化估读，保留坐标标定及分辨率误差；不得写成原表精确值。当前应用原表曲线通道不接受这类数据，需另存研究数据，不能绕过既有验证。只有f2、限度或结论不能生成逐点曲线。

不将不同pH、介质、转速、储存状态的Q直接相减。研究内配对差值可计算，但研究间对比要先核对响应定义和条件；相对差值/无量纲化也不会自动消除混杂。

## 3. 把机制拆成可验证关系

候选结构为：组成和阶段 → 形成的微结构/液体接触/颗粒分散 → API可接触状态 → 释放。逐边建立“关系卡”：

`edgeId, inputs, output, equationOrRelation, units, evidenceIds, measuredIntermediates, assumptions, competingMechanisms, fittedParameters, applicableDomain, falsificationCheck, transferStatus`

先判断控制环节与时间尺度：壳开启、液体进入、内容物解聚、颗粒溶解、析出或介质容量限制是否可能共同存在。不能把全部延迟塞入一个参数后称完成机制解释。

可以考察但不能默认套用的理论包括毛细进液、润湿接触、孔隙传输、溶解传质/缩粒、颗粒群或解聚动力学。每次真正采用前查原始理论和适用实验：变量能否测得，单位是否一致，几何与稳定性假设是否成立，是否遗漏膨胀、反应或析出。理论名词本身不提供本配方的参数。

从质量分数到体积分数需要相应密度依据；混合孔隙不等于组分孔隙线性平均。填充体积、压实状态和颗粒分布变化可能是替换效应的一部分。没有这些证据时保留竞争情景，不凭质量比生成孔隙或有效面积。

将以下层次分开：
- 来源观察：某对照中Q/中间量变化多少。
- 经验关系：在规定实验设计内的响应函数，尚不解释机制。
- 机制支持的关系：模型结构与中间量均有独立证据，可作限定迁移。
- 目标核验：迁移到目标后是否能解释预先保留的数据。

统计估参、分层模型和误差分析可辅助机制建模，但仅增加文献数据后拟合Q不能升级为机制模型。没有中间物性时，整条曲线往往不能区分不同路径；报告可识别的组合参数及不能分离的因素。

## 4. 对每条关系做迁移审查

| 维度 | 需要比较 | 可接受处理 |
| --- | --- | --- |
| API与介质 | 电离/盐/晶型、介质中实际溶解度、粒度、剂量与容量、表活/析出 | 可用目标物性重算的单列；未建模的结构差异不能用通用倍率补偿 |
| 辅料身份 | 牌号、粒度、天然/预胶化/改性、干粉/浆液 | 身份不符保留局部启示或另开分支 |
| 结构形成 | 湿法/直混、制粒液、润滑混合、压实与剂型 | 片剂中间物性可启发胶囊研究；强度/崩解曲线不直接迁移 |
| 测量与范围 | 方法、时间、储存、浓度/用量及交互因素 | 域内与域外分开，未报告即未知 |

每条边给 `supported_within_domain / requires_target_calibration / mechanism_only / incompatible / unknown` 及理由。不是全篇打一个“相似度”。可迁移方程结构不等于可迁移系数；局部进液关系成立也不等于整方净溶出方向成立。同BCS分类既不是充分条件，也不阻止其他分类贡献局部机制。

参数分别登记：来源实测、目标实测、来源拟合、目标校准、明确假设。不得把反算值改标实测。传播输入范围与模型结构差异，工程敏感性范围不称置信区间。

## 5. 验证与交付

先检查单位、质量守恒、范围和数值稳定性，再检查残差、参数识别及中间物性是否符合实验。校准后按研究/药物留出检验，数据预处理和模型选择也不能偷看留出组。保留方向错误、无效和失败案例；用它们决定模型分支，不事后删除以提高拟合。

交付至少包含问题卡、检索台账、逐研究数据、关系卡、迁移表、计算/残差与未覆盖因素；即使不能输出调整预测，也应交付已得到的物性关系与来源对照。缺少某条关系时，先针对它补查公开证据；仍不足再提出最能区分竞争机制的实验，说明测什么能更新哪个参数。不能把新增实验作为开始文献研究的前提。
