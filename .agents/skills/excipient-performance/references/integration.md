# 当前试用包接入约定与验收

2026-09-21已完成研究流程、固定计算器及双栏报告归档的首轮应用接入，见下节。后续数据契约与行为验收仍是扩展设计，不代表全部实现，也不代表其它辅料定量映射已经校准。

## 已实现的应用接入

- 2026-09-21 实际复用调试：新增 `calculate_powder_yield(input_json, source_ids)`，固定加载 `linear-powder-yield-v1`，输入来源URL须与本项目绑定证据一致，自动保存模型阶段及完整计算输入输出。其他模型无需本地脚本执行权限。来源检查证明项目归属与URL匹配，不证明参数正确或全文完整。示例JSON随技能加载，仅供接口示范，不能默认用于目标物料。
- 比较结果直接显示本轮剪切参数重建表，明确非原始逐点值、非目标溶出预测；源数据和历史报告仍保留。模型数值表不必等待双栏报告发布才可见。

- `excipient_skill.py`读取本地技能、通用双栏流程与跨药物研究流程；`capsule_research.py`将其加入研究指令并冻结内容及哈希。研究工具可查原文、调用注册计算器、归档双栏报告。
- `calculate_effective_rate_transfer`实现显式综合速率迁移情景：来源两组联合拟合、目标基线插值和时间尺度调整；它不是粒度/接触角/分散参数齐备的物理模型，更不是其它辅料通用系数。其它机制缺计算实现或证据时应保留缺口。
- `publish_excipient_comparison`仅接纳本项目的已读来源证据ID，校验双栏结构，生成报告和残差审计，按假设证据归档。模型文本或公式不作为代码执行。人工导入既有核对报告可不绑定项目来源ID，来源仍须在冻结报告中保留。
- 前端“辅料替换验证”页展示归档报告，并把项目已保存比较方案带入研究问题；点击入口只预填，用户点击开始研究后才运行。归档是冻结情景，不是当前处方自动预测；不改处方、实测或采纳参数。
- 报告文件按项目及证据ID读取，限定文件名，支持完整报告和冻结输入下载。

验证：`tests/test_excipient_skill.py`覆盖技能读取、固定计算器回放/零替换、超界拒绝、项目归档去重和文件隔离；与两组研究测试合计13项通过，类型检查与trial构建通过。真实氟桂利嗪项目已归档既有吡罗昔康→氟桂利嗪10mg乳糖替换演示；页面报告图、研究预填通过浏览器验证，记录见`reference/paired-skill-generalization-20260921/app-ui-check.json`。本轮未提交新的联网研究，不能宣称新的全流程研究已验收。

## 现有模块的可复用边界

- `apps/web/src/app/AdjustmentOutlook.tsx`：已有实际差异和机制展示，可承载按方案的分析结果。
- `apps/web/src/app/formulation-physics.ts`：已有显式物性输入的数值求解；不会从辅料量自动得到物性。无依据的参数不能由模型填默认值。
- `apps/web/src/app/anchored-inverse.ts`：来源曲线反算综合速率和开启时间；当前限定条件见代码。不能把拟合参数视为独立辅料系数，工程候选范围不是置信区间。

路径相对试用包根目录。接入前重新检查实现、项目保存协议和研究服务入口，不改原版或依赖目录链接。

## 接入需要的三部分

1. 服务端研究流程读取技能并提取证据，产出结构化分析；模型生成的文本不得直接成为可执行公式或数值参数。
2. 独立、版本化的映射目录保存经审核的函数及适用条件。计算器只调用已实现函数，校验输入、单位、来源、范围和缺项；不得执行来源或模型输出中的代码。
3. 前端按方案展示结果类别、差值、依据和缺口。经用户采用的参数与研究建议分开保存，原始证据和历史保留。读取技能文件本身不等于完成以上接入。

## 建议的数据契约

以下为设计字段，应用实现时须建立严格类型与运行时校验：

| 字段 | 含义 |
| --- | --- |
| schemaVersion / skillVersion | 当前接口设计版本4，增加双栏案例/目标、指标路由与迁移参数依据；独立报告输入schema_version=1为另一契约，不等于应用协议。既有v2/v3归档保持原样 |
| context | 项目、原方案与调整方案ID、处方/工艺/方法签名、数据修订 |
| changes | 数值、单位、质量基准、规格、加入方式、总量与补差变化 |
| roles | 物料ID、声称功能、确认用途、机制推断、来源与条件 |
| pathways | 因素、中间属性、指标、方向或冲突、证据ID |
| searchAudit | 日期、渠道、确切查询、已筛选范围、纳入/排除、全文状态、引用追查、未覆盖路径；stoppingReason区分阶段性饱和与资源停止 |
| studyArms | studyFamily/experiment/batch/arm标识；药物、辅料、工艺、方法、逐点与中间物性、原单位、转换及误差；BCS声明附来源 |
| mechanismEdges | 逐边输入/输出/方程及单位、实测中间量、来源、假设、竞争机制、适用域、识别情况及反证检查 |
| transferChecks | 每条边的来源→目标差异、可迁移结构、不可迁移系数、需重算/校准的目标量与未建模差异 |
| mappings | 注册模型ID/版本、输入参数及依据、适用域检查、遗漏因素 |
| resultKind | source_contrast / mechanism_only / conditional_scenario / quantitative_estimate |
| validationStatus | unvalidated / calibrated / independently_checked，另存数据集与指标 |
| results | 指标、单位、原方案值、调整值、差值、曲线；不可算为null并给原因，不能置0 |
| provenance | 原文定位、摘录、数据来源、迁移假设、计算器版本、训练与验证数据ID |
| validationDesign | 研究/药物/处方/批次分组、同源数据族、训练/调参/留出ID、是否使用目标数据校准；数值复核与外部验证分开 |
| gaps / nextExperiments | 具体缺口、区分机制的设计、所需测量、预期更新的映射 |
| pairedCase | 来源原/变化方案、来源数据/模拟分组、目标原/变化方案及基线/预测分组，独立方法和来源定位；列出全文组成差异 |
| endpoint / modelRoute | 响应名称、横纵轴及单位、参考范围；按辅料实际作用选择模型，不默认所有响应是溶出或使用统一速率缩放 |
| parameterProvenance | 每个参数值、单位、来源实测/拟合/目标校准/明确假设、原文或推导定位；没有依据不能隐藏在默认值中 |

字段枚举只控制展示，不证明科学有效。`quantitative_estimate` 仍需显示是否独立验证；`conditional_scenario` 必须展示假设值及由来。每个参数独立记录依据，不能用报告整体的证据等级覆盖无依据参数。

逐边迁移状态使用 `supported_within_domain / requires_target_calibration / mechanism_only / incompatible / unknown`，每项必须附理由。`dataOrigin`区分原表、图上估读、作者文本、来源拟合、目标校准和用户假设；图上估读不能写入现有仅接纳原表值的溶出通道。全文未读的数据不得标原表核验。BCS未知值不可默认II类。

未覆盖的关键变化应由确定性逻辑检查，不能仅依赖提示词。处方或方法变化后旧分析标记过期；项目保存/导出携带输入签名、分析结果及版本。密钥只在服务端。

## 行为验收案例

这些是验收输入与判定标准，不是实测数据或已通过的应用测试。

1. 只给原处方一条溶出曲线，要求乳糖、MCC、淀粉贡献百分比：可以研究综合拟合，必须说明单辅料效应不可辨识，不输出贡献占比。
2. 恒总量把10mg乳糖换成10mg淀粉，未给淀粉形态或工艺：显示两物料变化、形态分支与缺口；没有适用映射不生成确定预测。有真实对照及可解释的显式迁移假设时允许条件情景，注明需要实验确认和未覆盖因素，不冒充完整物性前向模型。
3. 同名MCC由101换102，手头数据是不同压片力的片剂硬度：保留原数据与混杂条件，不作为本胶囊的溶出系数。
4. 用户给定有效暴露比例0.4与0.6，其他所需物性均有依据：可以通过已有求解器进行条件情景比较；不能声称辅料替换已使该比例变为0.6。
5. 同时改变润滑剂和填充剂，映射只覆盖填充剂：阻断整方预测，指出遗漏因素；隔离敏感性结果不得命名为实际调整预测。
6. 有同体系多批对照及适用映射：输出带单位的方案差值、残差和校验域；按独立批次分组验证，重复杯不冒充独立批次，补差成分计入比较。
7. 处方、工艺、方法或证据修订后重开：旧结果仍可追溯但须标过期，不自动覆写新参数或实测。
8. 目标药没有直接替换研究，但另一难溶药物有乳糖/淀粉对照：继续获取该研究原文与中间量，不能仅因药名不同排除；逐边判断迁移，不能直接复制Q曲线。
9. 用户说两药都属于BCS II：记录分类依据；仍比较电离、盐/晶型、介质、粒度、辅料与工艺，不能自动生成统一系数。不同BCS但有匹配粉体进液证据时允许局部机制纳入。
10. 一篇研究用天然淀粉，另一篇用SSG：分别存身份；SSG协同改善不证明天然淀粉替换必然改善。甲芬那酸摘要提示无明显改善时应保留反例并取全文。
11. 多药物Q数据拟合R²很高，却没有中间物性：标经验关系，不能升级机制模型；指定按药物/研究留出而非随机拆时间点。
12. 独立进液/孔隙证据支持局部关系但API盐和介质不同：可迁移结构与需要目标重算的参数分开，先补查目标物性；不能一概拒绝迁移或凭空补系数。
13. 只有摘要/f2而有公开PDF入口：继续取得全文/补充材料，失败留台账，不伪造曲线；既有“未知”不是停止研究的理由。
14. 同一专利家族和论文重复实验：归同一studyFamily，不分散进训练与测试；目标数据参与校准后不再声称未见目标验证。

接入前应在独立输入上执行行为验收，再验证保存/恢复、单位与缺项拦截及trial构建。技能格式校验不能替代这些验证。
