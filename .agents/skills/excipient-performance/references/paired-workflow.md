# 通用辅料：左侧案例，右侧目标

## 交付顺序

1. **定义变化**：目标API/盐与剂型、原/新全部组成、规格、加入阶段、工艺及检测方法。恒质量替换列出补差物料；修改粒度也算变化。先用已有项目资料，缺项不猜。
2. **找对照案例**：不限药名或BCS，从相同辅料变化、相同结构形成工艺及相关机制测量中选择。优先一篇有同方法原/新方案、完整组成和逐点结果的原始研究；也纳入反向/无效案例。不能从多个研究各取一条曲线拼成成对试验。
3. **提取并冻结**：原表优先；图上估读保存原图定位、坐标标定、舍入、可辨识的误差类型。只有摘要/f2/限度继续补查，不生成曲线。原方和替换方的全组成/方法均保留，多因素变化明示。
4. **选模型**：使用下表按控制环节选择；检查单位、守恒和适用域。优先独立中间物性→性能；只能识别综合参数时采用明确命名的降阶模型，不把综合速率称作单辅料分散贡献。试图解释的指标应与实测相同，不能由崩解时间生成溶出率。
5. **左侧计算**：原/新两组实测标记与模拟线，参数表、逐点残差、RMSE及最大偏差。分别注明“同数据校准”“未参与拟合的处方检查”或“独立研究验证”。数据足够时冻结模型后留整处方/批次检查；不随机拆时间点冒充独立验证。失败案例保留。
6. **右侧迁移**：用目标物性重算可重算项；采用来源系数的部分逐项解释。目标原曲线必须有身份（目标实测/专利来源/明确假设）。标为条件预测时，明示变化幅度、方程、参数来源、未覆盖的作用及“需要实验确认”。不把源药绝对Q或崩解时间直接复制到目标。
7. **形成对照页**：顶端左右处方与全部变化；中间左右图；下方误差/预测读数；展开原始图表、计算、迁移条件、反例及数据下载。不是每条响应都需要时间曲线：单终点用点图，浓度/压力响应使用相应横轴。
8. **冻结与回验**：保存输入快照、来源/模型版本、拟合集和留出集、参数依据、预测时点与实验计划。后续目标实验独立入库，对比冻结预测；重拟合生成新版本，不能改旧预测以制造准确性。改变处方/方法后标旧结果过期。报告不自动成为实验或处方。

## 各类辅料选择不同控制环节

以下是研究和模型路由，不是已经校准的参数库。使用候选关系前仍须取得适用原始证据和实际实现；本技能当前可执行物理原语集中于填充剂，通用报告层支持其他指标。

| 辅料作用及典型任务 | 首先寻找的中间测量 | 候选模型及分支 | 不应沿用的假设 |
|---|---|---|---|
| 填充剂：乳糖、MCC、淀粉、甘露醇等互换或规格变化 | PSD/d32、外面积、混合/湿润后API粒度、孔隙/进水 | 面积/占位、进水、解聚与传质；见filler-mechanism | 不同牌号共系数；d50当d32；细化必定改善流动 |
| 崩解剂：原生/预胶化淀粉、SSG、CCS、交联PVP | 吸水、膨胀、应力/粉塞或片剂破碎、碎片粒度 | 进水与膨胀/破裂阈值，解聚及后续API溶解分别求解 | 崩解更快必然溶出更快；SSG与原生淀粉共身份 |
| 黏合剂：PVP/HPMC等品级、量、内外加或溶液加入 | 黏度、黏结/颗粒强度、孔隙、颗粒破碎、包埋 | 制粒形成关系→颗粒进水/破碎；可溶桥溶解；凝胶分支 | 更换聚合物只改一个速率；片剂强度就是胶囊性能 |
| 润滑/抗黏附：MgSt、硬脂酸、硬脂富马酸钠、滑石 | 比表面、覆盖、动态润湿、剪切历史、摩擦/顶出力 | 覆盖/润湿与混合动力学；压片机械指标单独分析 | 恒mg即恒覆盖；润滑改善即溶出改善；漏掉补差物料 |
| 助流：不同二氧化硅等规格/量/加入顺序 | 剪切流动、密度/充填变异、接触/包覆、混合均匀性 | 接触力与摩擦/粉体屈服；充填量及变异模型 | 流动角/Hausner比直接变成Q系数；不同亲疏水硅共用参数 |
| 表活/增溶：SLS、聚山梨酯、泊洛沙姆等 | 动态张力/角、游离与总溶解药物、聚集及浓度响应 | 润湿与分散；增溶/结合/析出分开，质量守恒 | 总增溶量等于自由药物浓度；所有剂量线性有效 |
| pH调节/缓冲辅料 | 缓冲容量、微环境pH、盐/晶型、溶解/析出 | 酸碱平衡和局部传质/析出；剂量与介质容量 | 把介质pH当颗粒表面pH；只迁移速率忽略Cs变化 |
| 缓控释基质/膜材 | 吸水、凝胶/膜厚、扩散、溶胀/侵蚀、孔隙 | 扩散-溶胀-侵蚀或膜传质，按结构选择 | 通用即时释放时间缩放；Higuchi等经验拟合就是机制验证 |
| 抗氧剂/稳定剂 | 杂质随时间、氧/水/光/包装与温度、含量 | 有证据的反应网络或降解动力学；环境耦合 | 单储存终点估速率；把抗氧剂添加量视为线性保护倍数 |

同一辅料可能跨行：按此处方实际用途和加入方式路由，保留交互项。独立流动、硬度、稳定性响应可用同一双栏展示，但不合并成一个“性能总分”。其它未列辅料沿“作用→中间量→性能”新增模型卡，不强塞现有类别。

## 允许使用文献效应条件迁移，但不隐藏其闭合关系

可复用的是方法，不是具体β。氟桂利嗪示例：来源Q=Qcap(1−exp(−kt))，由两组k估β=Δlog(k)/Δx，再假设目标所有相关速率统一缩放a=exp(λβΔx目标)，得到Q新(t)=Q原(a t)。这属于综合有效速率迁移，**没有证明组成→粒度/润湿的前向关系**。

只在相同响应、明确组成坐标x/分母、时域足够、单一统一时间尺度假设可解释时考虑此分支。新的辅料若改变滞后、最终释放量、溶解度、析出、凝胶/侵蚀或控制环节，不能只套时间缩放。给不出合理方程/参数时先补查案例及物性，右侧暂列未定参数。标签不能弥补错模型。

λ只能作为明确的迁移假设，不是概率或从BCS推出的数值。读图误差、来源实验误差、模型误差、跨体系迁移误差分别列出。只有读图扰动时不能画“预测置信带”。模型误差较大/系统性失配时展示失败，不用更好看的任意曲线取代数据。

## 通用报告输入与执行

`scripts/paired_case_report.py CASE.json --output REPORT_DIR`。使用有numpy/matplotlib的Python环境。脚本对传入的计算结果进行结构校验、残差计算与展示，**不执行JSON中的公式、不研究、不自动估参**。输入中数学关系为说明文本，模型参数须由前述研究与对应计算器生成。

输入版本`schema_version: 1`，必需结构：

```json
{
  "schema_version": 1,
  "title": "辅料替换对照",
  "endpoint": {"name": "累计溶出", "x_label": "时间", "x_unit": "min", "y_unit": "%", "bounds": [0,100]},
  "source": {
    "title": "来源药物/研究",
    "method": "实际方法，缺失项明确",
    "changes": "完整变化和补差/混杂",
    "references": [{"label": "原文及定位", "url": "https://example.org/original"}],
    "series": [
      {"id":"before-data","label":"原方","kind":"observed","origin":"figure_digitized","points":[[10,50],[20,70]]},
      {"id":"before-fit","label":"原方模拟","kind":"simulation","comparison_to":"before-data","evaluation":"calibration","points":[[10,49],[20,71]]}
    ]
  },
  "target": {"title":"目标药物","method":"目标方法","changes":"目标完整变化","references":[],"series":[],"gap":"若未计算，具体缺口"},
  "model": {"id":"模型ID/版本","equation":"实际方程和单位","parameters":[{"name":"参数","value":1,"unit":"单位","basis":"来源拟合/目标实测/明确假设","source":"来源定位或推导"}]},
  "transfer": {"assumptions":["具体假设"],"uncovered":["未覆盖作用"],"status":"conditional"},
  "validation": {"status":"calibrated","calibration_families":["study-A"],"validation_families":[]}
}
```

上例是字段说明，数值为合成示例，不能当真实文献执行。真实输入应含来源原/新方案的成对`observed`和对应`simulation`；模拟需覆盖每个对照点且时间坐标吻合。`origin`须为`original_table / figure_digitized / author_text / target_measurement / explicit_assumption / source_interpolation`之一；后两项只允许作为目标基线，不能冒充来源实测。未知不用0补。

目标的`kind`为`baseline`或`prediction`；每条`prediction`须有`comparison_to`指向基线并填`classification: conditional`。有预测就必须有迁移假设和参数依据。没有目标结果时留空`series`并填写`gap`，不要填假点。模板支持单点终点对照；界面称“指标”而非强行称溶出。

`bounds`只做数据提示，实测超过100%不得裁剪；参数、来源、预测可用域由研究人员另行判断。`validation.status=independently_checked`时必须给不同studyFamily的校准/验证ID；脚本只能查ID不重叠，不能证明独立性，界面保留该限制。

真实示例输入及工具回放见试用包 `reference/paired-skill-generalization-20260921/`。原吡罗昔康计算仍在 `reference/substitution-transfer-20260921/run.py`，不要改写其历史数据。


### 来源对照缺失时的归档
没有可核对的来源成对数值时使用 `report_kind: mechanism_gap`：缺数据的一侧设置`series: []`，已有来源observed或目标baseline必须保留，各自填写非空字符串`gap`（具体缺口），仍保留title/method/changes/references；model写id=not_calculated、equation=未计算、parameters=[]；transfer保留uncovered，validation.status=unvalidated。此分支允许展示已有原始观察点和来源身份明确的目标基线；禁止模拟/预测曲线。没有模拟不等于没有数据，禁止为了通过契约把已有数值藏进changes。来源正文与表格矛盾时保留表格标签与数值，并显式标记冲突、暂不校准。来源数据、来源模拟、目标基线、调整预测四步独立陈述，不混为一个缺口。归档校验失败只修正一次；仍失败则在研究报告中交付缺口，不猜测字段或用合成数据探测接口。
