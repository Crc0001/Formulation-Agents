# 辅料模型检验与迁移

输入为规格专项数据包、明确方程、参数依据及计算实现。按以下顺序检查，不把某一层通过升级成下一层通过。

验证声明须注明本轮实际执行的工具/输入/输出或既有测试记录。计算出标准例不等于本轮执行了零变化、独立求解和极限测试；没有调用记录时写“沿用既有软件检查，本轮未重跑”，不能补写通过。对τ=C+σtanφ，在C、σ固定且σ>0时φ增大使τ增大；不要将φ下降写成剪切阻力增加。未知目标规格时不预设其φ变化方向。

1. 数值正确性：单位和质量基准、守恒、零变化、边界行为、步长/网格收敛及必要的独立求解检查；保持原始数据，包括超过100%的实测值。不把软件测试叫药学验证。
2. 来源复现：先在来源药物和原方法上重现原方与变化方。展示实测点、模拟、逐点残差和误差单位。对系统偏差、边界参数、不可辨识和竞争模型作解释，不以较低RMSE证实某一辅料机制。
3. 留出验证：按研究/药物/批次分组，不能随机拆同一曲线时间点，也不能把专利同族/转载分散到训练测试。资料不足时明确只有校准，不能宣称泛化已验证。
4. 目标迁移：逐条比较API、规格、用量坐标、工艺、介质和测法。区分可迁移结构、需目标重算的物性、需重新估计的参数。目标数据参与估参后改称目标校准。

## 双栏交付与科学完成标准

左侧固定来源身份、对照全组成和方法，分别标实测/估读/拟合/独立验证。右侧固定当前方案的真实差异、基线来源、候选规格分支、预测假设和未覆盖作用。无依据的数值不填零，无有效映射不画伪曲线。性能指标不能互代；相对变化有依据但绝对基线缺失时只给可算相对量，不借其他处方曲线填补。

灵敏度范围、候选规格情景和统计置信区间分别命名。结论对应具体条件，不以“低可信度”放行无依据的整方曲线。不把参数敏感度称为辅料独立贡献。

遵循总技能的双栏数据契约。证据不足使用`mechanism_gap`交付已完成的研究、具体模型阻碍及下一步；这是阶段成果，不是性能研究完成。科学完成至少需：可复查数据、可执行计算、来源复现、迁移边界和能检验预测的实验方案。其后仍需目标实验确认。

提出能区分机制的实验：先确定对照及保持条件，再选中间物性和性能终点、独立批次与重复、评价阈值依据和将更新的参数。不要简单要求“再做溶出”而不说明它能识别哪个未知量。

程序支持时用`save_excipient_stage`保存验证记录；最终归档失败只修正一次，不能用试造数据探测接口。保存研究与未完成项，后续从阶段记录续接，不重复从零检索。
