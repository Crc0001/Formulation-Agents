# 辅料规格专项证据

输入为项目原方、一个已修改方案及其全部差异。没有变化的方案不启动专项。每个变化物料单独编号，恒总量替换将补差物料链接到同一对照；总量不变不表示规格效应为零。

## 身份先行，但身份未知不阻断研究

核对原专利原文、商品名、生产商、牌号历史版本、来源植物/化学形态、加工方式、结晶/无定形及水合状态。粒径须记录d10/d50/d90/d32、筛目或均值的口径及测量方法，不能互换。记录流动、堆密度、振实密度、含水、比表面积、润湿/接触角的测试条件，不从辅料通用名填值。

原文仍未明确时，建立有真实来源的候选规格分支，每个分支注明为什么可能对应；不声称已识别用户来料。分支优先选择可区分机制的规格，不遍历任意粒径。未知变量保持未知，后续由模型技能确定能算什么。

## 三条相互补充的检索路径

1. 同物料不同牌号/粒度/形态的成对研究，不限药物，也不以BCS分类为纳入门槛。
2. 规格→中间物性实验：粒径分布、表面形貌、粉床孔隙、流动、混合均匀性、进液、解聚、膨胀、压实或润滑覆盖。
3. 中间物性→制剂性能：以同工艺/同测定方法的对照为先，记录剂型、API性质、装量、壳、压实和润滑条件。

每条路径记录确切查询、渠道、日期、命中/排除理由和全文取得情况。优先处理可获得原文的高价值命中；追查引用与被引资料、专利族原语言、作者仓储和供应商技术实验。访问失败后选择替代原文入口，不反复请求同一被拒地址。Cookie/验证码页、摘要页、只有导航的HTML不能标记全文已读。PDF有图表时查看实际表图；仅有f2或结论不能生成曲线。

阅读数篇资料不是完成标准。交付须覆盖关键机制路径、正反例、混杂因素及已有证据是否足以识别参数；资源用尽记录为资源停止，不称检索穷尽。对于关键缺口给下一条具体查询和预期可取得的变量，避免笼统要求用户做实验。

## 粒度专项的深入检索

不要只查“辅料名 + dissolution”。将查询拆成同牌号筛分对照、跨牌号/形貌对照、API混合与团聚、润湿进液、工艺耦合五组。查询应包含具体测量量，例如 lactose sieved yield locus cohesion internal friction；lactose fines API agglomerate particle size dissolution；lactose particle size lubricant mixing tensile strength。优先同牌号筛分以减少形貌混杂，但仍核对筛分是否同时改变形状和表面。

查不到全文时，用精确标题、DOI查作者仓储和补充材料；核对DOI对应的PII，不把错误PII的访问失败算作全文不可得。搜索引擎命中数不代表原文覆盖数。区分原始仪器数据、作者拟合参数及自己的重建结果。

已核验的乳糖入口：Cavalli 等 https://arxiv.org/abs/2508.16786 ，全文含补充材料，表4/6/7可用于粒度—黏聚及同牌号筛分对照；Razavi 等 https://arxiv.org/abs/1801.02577 ，用于粒度×润滑×压实强度。两者不能直接提供胶囊溶出系数。Allahham 2007 DOI 10.1016/j.ejpb.2007.04.013，正确PII S0939641107001567；截至2026-09-21本地只有摘要，不能由摘要“与D50平方相关”写成“平方反比”。本地核验和复算在 reference/lactose-deep-research-20260921/。

检索交接必须包含至少一个可用数值表或明确失败定位；有可用参数则实际复算局部响应，不再仅列模型名称。仍无可用数据时保留原文取得路径和具体下一查询，不伪造达标。

## 给建模技能的数据包

### 图片表格不能停在“文字未提取”

read_source返回source_images_json时，先按表号定位图片，再实际调用read_source_image(evidence_id,image_id)；旧归档网页可先用image_id=0取得清单。不重复整页下载来期待图片变成文字。返回OCR保留单元格坐标、分数和原图证据；它不是已核验实测。将小数逗号、表头时间、样品A/B、均值/SD/逐杯数据分别核对，能取得原图时逐格核验；不能识别的格子留空。文字识别不能从溶出曲线的轴刻度生成曲线点。

已有两组相同时间的表值时，先计算来源观察差值并展示原始表值；没有目标迁移模型不妨碍交付来源数据。超过100%的来源值保留，不裁剪以满足现有速率求解器。不要把“无法迁移到目标”写成“来源无数据”，也不要把“调整方案无实测”写成“原方没有来源基线”。

每条研究保留study_family、原始URL/DOI、页/表/图、原文摘录、API与物料身份、各组完整组成、规格、工艺、方法、n及批次、数值和单位、数据来源类型及误差。图上估读单列误差来源，不冒充原始表值。相同研究的转载不得成为独立样本。

输出按专项编号连接：身份与候选分支 → 对照组表 → 可用物性/性能数据 → 反例及混杂 → 未取得变量及下一检索动作。交给`excipient-mechanism-model`；不能只给文献列表。程序提供`save_excipient_stage`时先保存证据阶段记录，避免最终报告失败丢失研究进展。

表格一致性检查须使用 calculate_table_statistics（或等价确定性计算器）复算逐列均值和样本SD，不能以模型心算宣称原表矛盾。保留原表舍入值与复算值，区分舍入误差。报告source_ids只放已读原始证据，不放hypothesis阶段记录；references.url使用原文http(s)地址，程序也可按本项目evidence:ID解析已有source_url。


接续工作先读取项目verification_records（来源版本、核验范围、核验主体和结论）。OCR原始unverified标记与后续独立视觉核验可以并存，不能只读旧标记忽略后续记录。核验值与科学适用性分开：视觉及算术核验通过不等于原文无矛盾或目标可迁移。


原始PDF的图像表格：read_source取得PDF归档证据ID后，read_source_image(image_id=0)查询物理页数，image_id=N读取第N页（从1起）。不能对read_patent仅正文证据反复调用图片工具；没有归档文件时先读取原始PDF。保留页码与原图，OCR候选不是已视觉核验。逐格核对列名、样品和单位；模糊单元格明确标未知，不以正文范围填补特定实验组。
