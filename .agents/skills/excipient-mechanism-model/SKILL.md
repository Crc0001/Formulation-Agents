# 辅料规格机制建模

输入为`excipient-grade-evidence`的专项数据包。每一变化物料都建立模型记录，记录可处于候选、可计算、已校准或受阻状态；有方程不等于已实现求解，有数值求解不等于药学有效。

## 数学化的最小交付

明确比较的响应y、单位、时间/空间尺度和参考方案。定义规格/组成/工艺向量x、中间状态z及可识别参数θ，分别写出规格到中间物性的关系z=f(x,θ)和性能关系y=g(z,API,介质,工艺)。列明每条关系来自物理定律、来源经验拟合、目标校准或明确闭合假设。只写这两个符号框架不算完成，须针对本专项给具体方程、边界/初始条件、参数表和证据定位。

优先建可检验的局部模型，逐步连接整方表现。不能由一条整方溶出曲线反推所有辅料的独立参数。统计方法可估参，但必须保留机制变量和不可辨识参数组合。

## 按作用选择子模型

| 规格/作用 | 应优先研究的中间量 | 单独核验的响应 |
| --- | --- | --- |
| 填充剂粒度、形态、溶解性 | 颗粒数与面积、混合/偏析、孔隙、进液、API团聚和暴露面积 | 装量/含量均匀性、润湿分散、溶出 |
| 崩解剂粒度、交联及取代度 | 吸水、膨胀、应变恢复、破碎阈值 | 内容物分散/崩解；再验证与溶出的连接 |
| 黏合剂分子量、黏度和加入形态 | 液桥、黏结、颗粒孔隙、强度及破碎 | 制粒、强度、分散和释放 |
| 润滑/助流剂面积、形态、混合时间 | 表面覆盖、黏附、摩擦、疏水进液阻力 | 流动/填充与润湿；不能只拟合用量 |
| 表活剂类型、浓度 | 润湿、聚集/胶束、自由药浓度和界面传质 | 分别核对表观溶解度与溶出 |
| 酸碱调节剂、释放聚合物 | 微环境pH、缓冲、溶胀、扩散和侵蚀 | API形态变化和释放 |
| 杂质、水分与稳定剂 | 反应物活度、接触、迁移和降解路径 | 有时间序列的稳定性指标 |

上述是路由，不是固定方向或已校准公式。填充剂任务继续使用总技能的`references/filler-mechanism.md`及显式参数计算器；其它类别先取得适用方程原始出处，再实现模型，不套用乳糖—淀粉β。

## 参数、计算与受阻分支

### 可计算的粉体流动分支

有同一预剪切条件下的来源参数时，先复算局部屈服关系 τ=C+σ tanφ（τ、C、σ为kPa；φ计算前从度转换为弧度）。C减小与φ增大可以同时发生，禁止将“粒度增大”固定映射为“流动改善”。C和φ是实验拟合参数，不是第一性原理常数；纯粉参数不按质量加权替代整方实测。

可移植计算器为本技能内的 `scripts/powder_yield.py`，仅需 Python 3 标准库，不访问项目数据库或网络。输入示例 `assets/powder-yield-example.json` 完整包含来源和条件；它使用来源表7同牌号筛分对照，不代表当前用户来料。表内筛分前dv50不得填到筛分后组；筛孔阈值不得作为dv50。平均C与平均φ重建不等于原始剪切点；重建误差不是独立验证。低应力代数交点没有原始实验支持时不升级为工艺阈值。

从本技能目录执行（其它工作目录使用实际绝对路径）：

```sh
python scripts/check_powder_yield.py
python scripts/powder_yield.py --input assets/powder-yield-example.json --output result.json
```

输入为JSON：`schema_version=1`、`model_id=linear-powder-yield-v1`、显式kPa/deg单位、同一预剪切条件、声明计算区间及依据、递增法向应力坐标、两个具有ID/物料/状态/C/φ/参数身份/URL/定位的组。以示例为结构模板；缺少参数时保持研究缺口，不用示例值补齐。输出含输入快照、两组τ、差值、相对变化、代数交点及限定，目标溶出固定为null。零基线的相对变化为null。拒绝区间外计算、非法数值和覆盖已有输出。

标准例在σ=0.5 kPa时应输出约0.37312656与0.52112890 kPa。相同参数应输出零差值。这验证计算执行，不证明来源或目标适用性。其它辅料只在已取得相同屈服关系及适用参数时使用此计算器；模型不从物料名称或粒径自动估计参数。

仅有研究API、没有文件执行权限的模型：检查实际可用工具是否注册此模型；未注册时提交上述输入包和待执行模型ID，标记“尚未计算”。不得以语言心算冒充脚本执行或调用不存在的工具。

目标溶出未定参时，仍交付已算局部物性、计算文件、来源表及缺失的连接关系。不得因为无法计算整方溶出就省略可算的局部模型，也不能把局部物性百分比变化直接乘到溶出速率。

每个参数记录数值/范围、单位、数据来源、测量条件、拟合方法、适用域和不确定性。供应商典型值只能作为所述产品条件情景，不填成本批实测。缺少目标规格时计算证据支持的候选规格分支；不赋予未经依据的概率权重。

使用已注册计算器；新模型先作为独立、版本化实现，通过量纲、守恒、零变化、极限行为和独立求解复核后再接程序。程序未暴露新模型求解工具时，明确记录待实现函数及输入输出，不把文字公式当可执行功能；不得用任意代码执行绕过工具边界。

映射受阻时给出已有可算局部量、方程、卡住的具体参数及最有信息量的补查/实验。局部结果不能冒充整方预测；关键同时变化因素未覆盖时不能输出整方净效应。交给`excipient-model-validation`检验。程序支持时用`save_excipient_stage`保存方程、参数表、计算版本、结果和受阻项，阶段未完成也可保存。


## 独立建模阶段的交付
已取得来源数据时，先保存来源观察对照，不能等待目标模型完成才交付。模型阶段须独立写明方程/单位、参数来源、可辨识性、校准数据、尚未解决的来源矛盾和下一项检验。无法拟合时保留所有来源点，具体列出受阻参数及需要的原文/测量，不输出伪拟合或把未校准降格为低可信预测。四项状态分别记录：来源数据、来源模拟、目标基线、调整预测。
