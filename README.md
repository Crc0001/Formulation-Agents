## 两个独立智能体

1. **原研及处方工艺**：独立任务与证据库。核对原研/参比身份、定量处方及对应工艺，输出有依据的推荐基准。研究结果不自动采用；核对后冻结新版本并交给第二智能体。专利实验对照不等于监管参比制剂。
2. **辅料筛选**：独立任务与证据库，只接收选定的基准及其引用。允许辅料品牌、牌号、粒径及正用量变化；服务器禁止新增/删除种类、改变API或壳。固定总量时必须显式补差，也可明确允许总量改变。

原研及参比数据库与辅料品牌规格数据库分开，研究结果有可读取来源时归档为待核研究条目。外部导入也是待核记录，不自动采纳为处方或模型参数。

## 图形与实验

- 来源溶出记录按原条件画图；辅料专项机理报告沿用有依据的计算器和双栏图形，工具输出与目标适用性分别记录。
- 本机提供Weibull局部释放计算：Q=100[1−exp(−(t/τ)^β)]，τ单位分钟。需要明确输入来源或显式假设，默认不填参数。此经验模型不是品牌/粒径到性能的自动映射。
- 实验保存方案快照、方法、批次、原始点及所选冻结模拟。至少3个不同正时间且0<Q<100、方法明确时用对数变换最小二乘估计τ与β；报告原百分比空间拟合RMSE及所选模拟RMSE。
- 这属于同体系经验校准，不是独立验证或辅料贡献拆解。不能把同一批时间点当独立批验证。不自动迁移到其他方案。
- 超100%、零值、数据不足等仍保存原值，当前模型不适用时不拟合、不裁剪。全部版本保留。
- 所选冻结模拟不自动证明它先于实验发生；用户须保留真实实验计划和时间记录。
